# Employee Payroll Management & Analytics

## 📌 Project Overview

This project is an **Employee Payroll Management and Analytics Dashboard** developed using **Microsoft Excel**.

The project analyzes employee payroll data to understand **salary distribution, employee details, attendance, overtime, deductions, departments, locations, and payment status**.

The dashboard uses **Excel formulas, Pivot Tables, Charts, and Slicers** to convert raw payroll data into meaningful insights.

## 🎯 Objectives

- Analyze employee payroll information
- Calculate gross salary, deductions, and net salary
- Analyze employee attendance and overtime
- Compare salaries across departments and locations
- Track payment status
- Create an interactive Excel dashboard
- Generate useful business insights from payroll data

## 🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas
- XLOOKUP
- IF / SUM / COUNTIF / SUMIF
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## 📊 Dashboard

The dashboard provides insights into:

- Total Employees
- Total Gross Salary
- Total Net Salary
- Average Salary
- Employee Distribution
- Department-wise Salary
- Location-wise Employees
- Overtime Analysis
- Payment Status
- Employment Type
